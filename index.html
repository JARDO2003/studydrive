Rédigez votre lettre

Remplissez l'adresse du destinataire et votre message. La lettre part directement depuis ce navigateur, sans serveur intermédiaire.

Ce site utilise EmailJS, un service gratuit qui envoie de vrais emails directement depuis le navigateur, sans backend.
  1. Créez un compte gratuit sur emailjs.com.
  2. Ajoutez un "Email Service" (ex. Gmail) — vous obtenez un SERVICE_ID.
  3. Créez un "Email Template". Dans le champ To Email du template, mettez {{to_email}} pour que le destinataire soit dynamique. Utilisez aussi {{from_name}}, {{from_email}}, {{subject}}, {{message}} dans le corps — vous obtenez un TEMPLATE_ID.
  4. Dans "Account" → "General", copiez votre PUBLIC_KEY.
  5. Ouvrez le fichier index.html et remplacez les trois valeurs en haut du script (PUBLIC_KEY, SERVICE_ID, TEMPLATE_ID) par les vôtres.
Le plan gratuit d'EmailJS autorise 200 emails/mois, largement suffisant pour un petit formulaire de contact.
